# Galaxy Fights — Unity Game Project

Galaxy Fights is a Unity game-development project. The repository includes Unity project settings and package configuration for **Unity 6 (6000.0.60f1)**.

## Built with

- **Engine:** Unity 6
- **Language:** C# (for project scripts)
- **Project configuration:** Unity Package Manager
- **Packages configured:** Input System, Shader Graph, Timeline, AI Navigation, UI, and render-pipeline packages

The project manifest includes both the Universal Render Pipeline (URP) and High Definition Render Pipeline (HDRP) packages. Confirm which pipeline the active scenes use before changing rendering settings.

## Open the project

1. Install Unity Hub.
2. Install Unity Editor version **6000.0.60f1**, or a compatible Unity 6 version.
3. Clone this repository:

   ```bash
   git clone https://github.com/meghp786-cpu/Galaxy-Fights---Unity.git
   ```

4. In Unity Hub, select **Add** and choose the cloned project folder.
5. Open the project and allow Unity to resolve packages and import assets.
6. Open the project's available scenes from the Project window and press **Play** to test.
